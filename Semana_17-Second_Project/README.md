
Please note that I have used two external libraries such as PySimpleGUI and matplotlib, hence, it's recommended to follow the steps below to properly use the app:

1. Create a virtual environment:
python -m venv venv

2. Activate the environment:
venv\Scripts\activate for Windows
source venv/bin/activate for Mac/Linux

3. Install the dependencies:
pip install -r requirements.txt

4. To execute the app run:
python main.py
